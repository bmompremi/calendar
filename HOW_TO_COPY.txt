🎯 QUICK REFERENCE - DATABASE CONNECTION STRINGS
────────────────────────────────────────────────────────────────────────────

Local SQLite:
  DATABASE_URL=sqlite:///haiti_bank.db

Local PostgreSQL:
  DATABASE_URL=postgresql://username:password@localhost:5432/haiti_bank

Local MySQL:
  DATABASE_URL=mysql+pymysql://username:password@localhost:3306/haiti_bank

Remote PostgreSQL:
  DATABASE_URL=postgresql://user:pass@your-server.com:5432/haiti_bank

Remote MySQL:
  DATABASE_URL=mysql+pymysql://user:pass@your-server.com:3306/haiti_bank

AWS RDS PostgreSQL:
  DATABASE_URL=postgresql://admin:pass@instance.region.rds.amazonaws.com:5432/haiti_bank

Heroku Postgres:
  DATABASE_URL=postgres://user:pass@host.compute.amazonaws.com:5432/dbname

Google Cloud SQL:
  DATABASE_URL=postgresql://user:pass@/haiti_bank?host=/cloudsql/project:region:instance

🔧 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

Problem: "ModuleNotFoundError"
Solution: Make sure virtual environment is activated
          source venv/bin/activate
          pip install -r requirements.txt

Problem: "Database connection failed"
Solution: Check database is running
          Verify credentials in .env
          Check firewall settings

Problem: "Port 5000 already in use"
Solution: Edit app.py, change to port 5001:
          app.run(debug=True, host='0.0.0.0', port=5001)

Problem: "Permission denied"
Solution: Grant database permissions
          PostgreSQL: GRANT ALL PRIVILEGES ON DATABASE haiti_bank TO user;
          MySQL: GRANT ALL PRIVILEGES ON haiti_bank.* TO 'user'@'localhost';
